# Plano de Estudos — Visão Geral

O assessment expira em **14 dias** a partir do envio. Este plano distribui o conteúdo de forma estratégica para maximizar sua preparação.

---

## Princípio Geral

```
Semana 1: Base técnica sólida (algoritmos + problemas do guia)
Semana 2: Reforço, system design e simulação de prova
```

---

## Distribuição de Tempo por Área

| Área | % do Tempo | Justificativa |
|---|---|---|
| Coding Challenge (algoritmos) | 60% | É a parte que mais elimina candidatos |
| System Design | 25% | Requer fluência nos conceitos |
| Behavioral / Workstyle | 15% | Menos preparação técnica necessária |
