# SDEII Online Assessment Preparation Guide
=================================================

### The Assessment:

1) Coding Challenge - A 100-minute HackerRank module featuring two coding challenges. One is the traditional code writing question (total time to complete is 40 minutes), and in the other you will have access to an AI coding assistant in a code repository environment (total time to complete is 60 minutes). 

2) System Design: Work Simulation – Typically takes 15 minutes

3) System Design: Work Style – Typically takes 5 minutes.

4) AA: Workstyles – Typically takes 8 minutes.

### Rules

-    It will consist of implementing algorithms primarily on Big (O)n and O(N logN) concepts. 

-    The best browsers to take the test are Google Chrome 94+ or Microsoft Edge 94+

-    Do not use AI or external tools to complete the assessment.  You are only allowed to use the one that the test provides.

-    Avoid switch windows during the exam, as this may be considered cheating. If you need to verify information, use a separate device, and remember that HackerRank doesn't allow pasting from external windows.

-   You can take the sample test as many times as you like, but you would need to use different email addresses each time.


The assessment supports C, C++, C++14, C#, Go, Java7, Java8, JavaScript, Kotlin, Objective-C, PyPy2, PyPy3, Python2, Python3, Ruby, Scala, Swift. This can be done anytime during the day/night on your own time; however, the assessment expires within 14 days from date sent. There will be detailed instructions once you select the link. You will need to select START TEST to start the timer.
