# Coding Challenge — Visão Geral

O desafio de código é realizado na plataforma **HackerRank** e tem duração total de **100 minutos**, divididos em dois módulos.

---

## Módulo 1 — Desafio Tradicional (40 minutos)

- Você escreve o código do zero, **sem assistência de IA**
- Foco em algoritmos com complexidade **O(n)** e **O(n log n)**
- Uma questão completa a ser resolvida dentro do tempo

### O que esperar:
- Problema de grafo ou árvore
- Possível uso de estruturas como heaps, filas, pilhas ou tries
- Entrada/saída formatada (leia com atenção o enunciado)

### Estratégia:
1. Leia o enunciado **completamente** antes de escrever qualquer linha
2. Identifique a estrutura de dados mais adequada
3. Escreva o pseudocódigo mental antes de codificar
4. Teste com os exemplos fornecidos
5. Considere casos extremos (input vazio, valores únicos, grafos desconexos)

---

## Módulo 2 — Desafio com Assistente de IA (60 minutos)

- Você trabalha em um **repositório de código** com contexto pré-existente
- Um **assistente de IA** está disponível dentro do ambiente HackerRank
- É permitido e encorajado usar o assistente fornecido
- Não use ferramentas externas

### O que esperar:
- Completar ou corrigir uma funcionalidade em um repositório
- Pode envolver múltiplos arquivos
- Compreensão de código existente é essencial

### Estratégia:
- Veja `ai-assisted-challenge/README.md` para guia completo

---

## Complexidades Alvo

| Complexidade | Exemplo de Algoritmo |
|---|---|
| O(1) | Acesso a elemento de array/hash |
| O(log n) | Busca binária |
| **O(n)** | BFS, busca linear, sliding window |
| **O(n log n)** | Merge sort, heap sort, operações de heap |
| O(n²) | Bubble sort — **evitar** |

> O foco do teste é **O(n)** e **O(n log n)**. Soluções O(n²) provavelmente não passarão nos casos de teste maiores.
