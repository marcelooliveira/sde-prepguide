# SDE II Online Assessment — Preparation Hub

Este repositório é o seu guia completo de preparação para o processo seletivo **SDE II** (Software Development Engineer II).

---

## Estrutura do Processo Seletivo

| Etapa | Descrição | Duração |
|---|---|---|
| **1. Coding Challenge** | HackerRank — 2 desafios de código | 100 min |
| └─ Desafio Tradicional | Escrita de código sem assistência de IA | 40 min |
| └─ Desafio com IA | Repositório de código com assistente de IA | 60 min |
| **2. System Design: Work Simulation** | Simulação de situações reais de trabalho | ~15 min |
| **3. System Design: Work Style** | Perguntas sobre estilo de trabalho | ~5 min |
| **4. AA: Workstyles** | Avaliação de perfil comportamental | ~8 min |

## Regras Importantes

- Use **Google Chrome 94+** ou **Microsoft Edge 94+**
- **Não use IA ou ferramentas externas** — exceto a fornecida no test
- **Não troque de janela** durante a prova (pode ser considerado trapaça)
- Se precisar consultar algo, use um **dispositivo separado**
- O HackerRank **não permite colar** texto de janelas externas
- A avaliação expira em **14 dias** a partir do envio — planeje com antecedência
- Você pode fazer o teste de exemplo quantas vezes quiser (use e-mails diferentes)

## Linguagens Suportadas

C, C++, C++14, C#, Go, Java 7, Java 8, JavaScript, Kotlin, Objective-C, PyPy2, PyPy3, Python 2, Python 3, Ruby, Scala, Swift

**Recomendação:** Escolha a linguagem com a qual você tem mais fluência. Python 3 é popular por sua concisão.

1. Leia este README completamente

6. Familiarize-se com os princípios de liderança da Amazon em `03-behavioral/`
