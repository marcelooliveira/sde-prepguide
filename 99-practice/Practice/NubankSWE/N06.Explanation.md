# N06 - First Missing Positive (Primeiro Inteiro Positivo Faltante)

## ?? Descrição do Problema

Dado um array de números inteiros não ordenado, encontre o **menor inteiro positivo** que está **faltando** na sequência.

### Exemplos:

**Exemplo 1:**
- **Input:** `[1, 2, 0]`
- **Output:** `3`
- **Explicação:** Os números 1 e 2 estão presentes, então o primeiro positivo faltante é 3.

**Exemplo 2:**
- **Input:** `[3, 4, -1, 1]`
- **Output:** `2`
- **Explicação:** Temos 1, 3 e 4. O número 2 está faltando.

**Exemplo 3:**
- **Input:** `[7, 8, 9, 11, 12]`
- **Output:** `1`
- **Explicação:** O número 1 não está presente no array.

### Restrições:
- O algoritmo deve rodar em tempo **O(n)**
- Deve usar espaço constante **O(1)** (não pode criar arrays auxiliares grandes)

---

## ?? Entendendo o Problema

### O que estamos procurando?

Queremos encontrar o menor número da sequência `1, 2, 3, 4, 5, 6, ...` que **NÃO** está no array.

### Observações importantes:

1. **Só nos interessam números positivos**: números negativos e zero não importam
2. **Só nos interessam números no intervalo [1, n]**: onde `n` é o tamanho do array
   - Por quê? Se temos um array de tamanho 5, o primeiro positivo faltante só pode estar entre 1 e 6
   - Se todos os números de 1 a 5 estiverem presentes, a resposta é 6
3. **Números maiores que n não importam**: por exemplo, se o array tem tamanho 5 e contém o número 100, ele não afeta a resposta

---

## ?? A Ideia da Solução

### Conceito Principal: Usar o Array como um HashMap

A ideia genial é usar **o próprio array** como uma estrutura de dados para marcar quais números estão presentes!

**Estratégia:**
1. Colocar cada número na sua "posição ideal"
2. A posição ideal do número `k` é o índice `k-1`
   - Número 1 ? índice 0
   - Número 2 ? índice 1
   - Número 3 ? índice 2
   - e assim por diante...

3. Depois de organizar, percorrer o array e encontrar o primeiro índice onde `nums[i] != i + 1`

---

## ?? Solução Passo a Passo

### Fase 1: Reorganizar os Números

Vamos reorganizar o array para que cada número fique na sua posição ideal (quando possível).

#### Exemplo: `[3, 4, -1, 1]`

**Passo inicial:**
```
Índice:  0   1   2   3
Array:  [3,  4, -1,  1]
```

**Iteração i=0 (valor 3):**
- O número 3 deve estar no índice 2 (posição 3-1)
- Trocar nums[0] com nums[2]:
```
Índice:  0   1   2   3
Array: [-1,  4,  3,  1]
```
- Agora nums[0] = -1, que não está no intervalo [1, n], então paramos

**Iteração i=1 (valor 4):**
- O número 4 deve estar no índice 3 (posição 4-1)
- Trocar nums[1] com nums[3]:
```
Índice:  0   1   2   3
Array: [-1,  1,  3,  4]
```
- Agora nums[1] = 1, que deve estar no índice 0
- Trocar nums[1] com nums[0]:
```
Índice:  0   1   2   3
Array: [ 1, -1,  3,  4]
```
- Agora nums[1] = -1, que não está no intervalo [1, n], então paramos

**Iteração i=2 (valor 3):**
- O número 3 já está no índice 2 (correto!), então não faz nada

**Iteração i=3 (valor 4):**
- O número 4 já está no índice 3 (correto!), então não faz nada

**Array final após reorganização:**
```
Índice:  0   1   2   3
Array: [ 1, -1,  3,  4]
```

### Fase 2: Encontrar o Primeiro Faltante

Agora percorremos o array e verificamos qual posição não contém o valor esperado:

```
Índice 0: nums[0] = 1  (esperado: 1) ?
Índice 1: nums[1] = -1 (esperado: 2) ?
```

O primeiro índice onde o valor não corresponde é o **índice 1**, então a resposta é **2** (índice + 1).

---

## ?? Explicação do Código

```csharp
public static int FirstMissingPositive(int[] nums)
{
    int n = nums.Length;

    // FASE 1: Reorganizar o array
    for (int i = 0; i < n; i++)
    {
        // Enquanto o número atual:
        // 1. Estiver no intervalo [1, n]
        // 2. NÃO estiver na posição correta
        while (nums[i] > 0 && nums[i] <= n && nums[nums[i] - 1] != nums[i])
        {
            // Calcular onde este número deveria estar
            int correctIdx = nums[i] - 1;

            // Trocar o número atual com o número na posição correta
            int temp = nums[i];
            nums[i] = nums[correctIdx];
            nums[correctIdx] = temp;
        }
    }

    // FASE 2: Encontrar o primeiro número faltante
    for (int i = 0; i < n; i++)
    {
        // Se o valor no índice i não é i+1, encontramos o faltante
        if (nums[i] != i + 1)
        {
            return i + 1;
        }
    }

    // Se todos os números de 1 a n estão presentes
    // o próximo faltante é n+1
    return n + 1;
}
```

### Por que usar `while` em vez de `if`?

O `while` é necessário porque após uma troca, o novo valor em `nums[i]` pode também precisar ser movido. Continuamos trocando até que o valor em `nums[i]` esteja correto ou não possa ser movido.

**Exemplo:**
```
[3, 1, 2] no índice 0:
- Troca 3 com nums[2]: [2, 1, 3]
- Agora nums[0] = 2, troca com nums[1]: [1, 2, 3]
- Agora nums[0] = 1, está correto!
```

### Condição `nums[nums[i] - 1] != nums[i]`

Esta condição evita loops infinitos quando há duplicatas:

```
[1, 1] no índice 0:
- Se tentássemos trocar nums[0] com nums[0], entraríamos em loop infinito
- Com a condição, vemos que nums[0] == nums[0], então paramos
```

---

## ?? Complexidade

### Tempo: O(n)

Embora tenhamos um loop `while` dentro de um loop `for`, cada elemento é movido no máximo uma vez para sua posição correta. Portanto, o número total de operações é proporcional a `n`.

### Espaço: O(1)

Usamos apenas algumas variáveis auxiliares (`i`, `temp`, `correctIdx`). Não criamos estruturas de dados adicionais.

## ?? Pontos-Chave para Lembrar

1. **Use o array como sua própria estrutura de dados** - não precisa criar HashMap ou Set
2. **Posição ideal = número - 1** - o número `k` vai para o índice `k-1`
3. **Só importam números entre 1 e n** - ignore zeros, negativos e números maiores que n
4. **Use `while` para continuar trocando** - um número trocado pode precisar de mais trocas
5. **Verifique duplicatas** - a condição `nums[nums[i] - 1] != nums[i]` evita loops infinitos
