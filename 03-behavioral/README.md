# Comportamental e Workstyle — Visão Geral

O processo inclui **duas etapas comportamentais** além do código e system design.

---

## Etapas Comportamentais

### 1. System Design: Work Style (~5 minutos)
Perguntas sobre como você trabalha tecnicamente:
- Como você toma decisões técnicas?
- Como você lida com discordâncias técnicas com o time?
- Como você equilibra velocidade vs. qualidade?

### 2. AA: Workstyles (~8 minutos)
Uma avaliação psicométrica de perfil comportamental:
- Apresenta afirmações e você indica o grau de concordância
- Avalia traços como proatividade, colaboração, orientação a resultados
- **Não há resposta "certa"** — seja autêntico, mas consistente com os valores da empresa

---

## Valores da Amazon (Leadership Principles)

A Amazon organiza seus valores em torno de **16 Leadership Principles**. Mesmo que o processo não mencione explicitamente, esses princípios influenciam toda a avaliação.

Veja o arquivo `amazon-leadership-principles.md` para detalhes de cada princípio.

---

## O Método STAR

Use este método para estruturar respostas a perguntas comportamentais:

| Letra | Significado | Exemplo |
|---|---|---|
| **S** | Situação | "Em meu último projeto, enfrentamos..." |
| **T** | Tarefa | "Minha responsabilidade era..." |
| **A** | Ação | "Decidi fazer X porque..." |
| **R** | Resultado | "O resultado foi Y, com impacto Z" |

---

## Dica Final

O avaliador quer ver que você:
1. Age com autonomia e dono do problema
2. Colabora bem e considera impacto nas outras pessoas
3. Usa dados para tomar decisões
4. Aprende rápido e se adapta
5. Tem alta barra de qualidade para si mesmo e para o time
